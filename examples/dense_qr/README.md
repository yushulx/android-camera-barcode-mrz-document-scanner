# High-density QR Code Detection 
This app demonstrates how to use ML Kit's Barcode Scanning API and the Dynamsoft Barcode Reader API to detect high-density QR codes. It supports:

- **Still image comparison**: a built-in high-density QR code sample (version 40, 177x177 modules, a 2,400-byte payload) is decoded automatically on launch. The sample bitmap is 380x380 px (about 2 px per module) and is displayed scaled up to screen width, so it is easy to see yet already too dense for Google ML Kit — Dynamsoft Barcode Reader decodes it, ML Kit does not. A panel shows each engine's result and latency side by side. Use the SELECT IMAGE / TAKE PHOTO buttons to test with your own photos.
- **Live camera comparison**: the LIVE CAMERA button opens a CameraX preview where every frame is fed to both engines, with their results and latency refreshed in real time.

The UI keeps the image/preview area fixed; detection results scroll inside a fixed-height panel, so the overlay stays aligned with the displayed image.

## Pre-requisites
- Obtain a [Dynamsoft Barcode Reader license key](https://www.dynamsoft.com/customer/license/trialLicense?product=dbr) to activate the Dynamsoft barcode scanning functionality. The public trial key in `DynamsoftBarcodeProcessor.java` requires network access for online license validation.

## Getting Started
1. Set your Dynamsoft license key in `app/src/main/java/com/google/mlkit/vision/demo/java/dynamsoftbarcodescanner/DynamsoftBarcodeProcessor.java`:

    ```java
    LicenseManager.initLicense(
        "LICENSE-KEY",
        new LicenseVerificationListener() {
            @Override
            public void onLicenseVerified(boolean isSuccessful, Exception e) {
            }
        });
    ```

2. Build and run the project in Android Studio. The project uses the latest Dynamsoft Barcode Reader bundle (`com.dynamsoft:barcodereaderbundle:11.6.2000`, which includes the Capture Vision core with `CaptureVisionRouter`). Taking a photo asks for the CAMERA permission.

## Command-line Build and Run
Prerequisites: JDK 17, Android SDK with `android-35` platform installed (set the `ANDROID_HOME` environment variable or create a `local.properties` file with `sdk.dir=<your-android-sdk-path>`), and a device or emulator with USB debugging enabled.

```bash
# Build the debug APK (use `gradlew.bat` on Windows)
./gradlew assembleDebug

# Output
app/build/outputs/apk/debug/app-debug.apk

# Install and launch on a connected device or emulator
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.google.mlkit.vision.demo/.java.StillImageActivity
```

The first build downloads Gradle 8.7 and all dependencies, so it may take a few minutes.

## Regenerating the Built-in Dense QR Sample
The built-in sample QR code (`app/src/main/res/drawable-nodpi/dense_qr_sample.png`) is generated by the Python script at the codepool repository: [`tools/dense-qr-high-density-demo.py`](https://github.com/yushulx/codepool/blob/main/tools/dense-qr-high-density-demo.py). It creates a version 40 QR code (177x177 modules) with a 2,400-byte payload.
