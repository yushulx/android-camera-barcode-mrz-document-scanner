# Document Scanner — Expo Example

A production-ready Expo (React Native) app that uses the [Dynamsoft Capture Vision](https://www.dynamsoft.com/capture-vision/docs/introduction/) SDK to scan, crop, and export documents from your device camera.

This app is the Expo counterpart of [`react-native-document-scanner`](../react-native-document-scanner): the **same UI flow and the same features**, driven by the same `dynamsoft-capture-vision-react-native` SDK inside an Expo project.

## Features

| Feature | Description |
|---|---|
| Auto-detect edges | The SDK automatically detects document boundaries in the live camera feed |
| Manual crop | Drag corner handles to fine-tune the crop region before confirming |
| Color modes | Switch between full color, grayscale, and binary (black & white) output |
| PNG & PDF export | Export the scanned document as a PNG image or PDF document |
| Share | Send the exported file straight to any app via the system share sheet |

## Requirements

- Expo **SDK 50 or higher** (this project targets SDK 57)
- A **development build** — the Dynamsoft SDK contains native code, so **Expo Go is not supported**
- Node 18+

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Run on Android

```bash
npx expo run:android
```

### 3. Run on iOS

```bash
npx expo run:ios
```

(On first iOS run, CocoaPods are installed automatically. Xcode + a signing team are required for a device build.)

You can also generate the native projects up front with `npx expo prebuild` and then run
`npm run android` / `npm run ios`.

> **Note:** `npx expo prebuild` only generates the `ios/` folder on macOS or Linux.
> On Windows, build Android (`npx expo run:android`) or run prebuild from a mac/CI for iOS.

### Type checking

```bash
npx tsc --noEmit
```

All app code under `src/` type-checks cleanly. TypeScript additionally reports a few
pre-existing, type-level errors inside the Dynamsoft SDK's own shipped source
(`node_modules/dynamsoft-capture-vision-react-native/src/…`). They do not affect
Metro/Babel builds, and 2 of them also occur in the original
[`react-native-document-scanner`](../react-native-document-scanner) example.

## License Setup

The app ships with a [trial license key](https://www.dynamsoft.com/customer/license/trialLicense/?product=dcv&package=cross-platform). To use your own key, open [src/App.tsx](src/App.tsx) and replace the string passed to `LicenseManager.initLicense()`:

```tsx
LicenseManager.initLicense('YOUR_LICENSE_KEY_HERE')
```

## Project Structure

```
src/
├── App.tsx              # Root navigator, HomeScreen, license initialization
├── Scanner.tsx          # Live camera screen — auto-detects and captures document
├── Editor.tsx           # Quad editor — drag corners to adjust crop region
└── NormalizedImage.tsx  # Result screen — color modes, PNG/PDF export & share
```

## How it differs from the bare React Native example

| | `react-native-document-scanner` | `expo-document-scanner` |
|---|---|---|
| Native projects | Committed `android/` + `ios/` folders | Generated by `npx expo prebuild` (git-ignored) |
| Entry point | `index.js` + `AppRegistry` | `index.ts` + `registerRootComponent` |
| Config plugin | — | `dynamsoft-capture-vision-react-native` in `app.json` (adds the Dynamsoft Maven repo) |
| iOS permission | `Info.plist` | `expo.ios.infoPlist.NSCameraUsageDescription` |
| UI & features | — | Identical |
