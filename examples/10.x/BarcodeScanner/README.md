# Android Barcode Scanner with Dynamsoft SDK
This repository demonstrates how to build a simple Android barcode scanner app using Dynamsoft's Ready-to-Use Barcode Scanner API . With just a few lines of code, you can integrate advanced barcode scanning capabilities into your Android application, supporting multiple barcode formats and real-time scanning.

## Prerequisites
- Obtain a free trial license from [Dynamsoft's website](https://www.dynamsoft.com/customer/license/trialLicense/?product=dcv&package=cross-platform).


## Getting Started
1. Clone the repository and open the project in Android Studio.
2. Replace the `license-key` in `MainActivity.java` with your own license key.
    
    ```java
    private final String LICENSE_KEY = "LICENSE-KEY";
    ```
3. Build and run the project.
